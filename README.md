# Olá! Eu sou o Renato 👋

Tenho 28 anos,sou Analista de Suporte de Sistemas e estudante de programação.

Minha jornada na programação começou com o *vibe coding*. Ao usar ferramentas de IA para criar projetos, quis entender melhor o código que elas geravam — e foi assim que comecei a estudar programação de forma mais aprofundada. Hoje, também estou aprendendo lógica e algoritmos, e buscando desenvolver autonomia para analisar, ajustar e refatorar código.

Este GitHub reúne meus estudos, experimentos e projetos enquanto continuo evoluindo como programador.
